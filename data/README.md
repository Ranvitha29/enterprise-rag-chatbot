Enterprise RAG Chatbot

Tech Stack:
- Python
- Ollama (Llama 3)
- Sentence Transformers
- ChromaDB

Features:
- Multi-document retrieval
- Vector embeddings
- Semantic search
- Conversation memory
- Local LLM inference

Workflow:
1. Load documents
2. Create embeddings
3. Store embeddings in ChromaDB
4. Retrieve relevant context
5. Generate answer using Llama 3
